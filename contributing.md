# Contribution Guidelines

Thanks for considering a contribution to Awesome Effect-TS!

Please ensure your suggestion meets the following criteria:

- **It is genuinely related to [Effect](https://effect.website)** — either built on Effect, a popular library shipping an Effect layer/adapter, an app built on Effect, or high-quality Effect content.
- **It is actively maintained and genuinely useful** — no abandoned proofs-of-concept, toy repos, or "started and never finished" projects.
- **It is not a core `@effect/*` package** — those are the framework itself, not ecosystem additions.

## Adding an entry

- Add your entry to the most fitting section, keeping the list format: `- [Name](link) - Description.`
- Write a clear, succinct description. Start with a capital letter and end with a period.
- Check your spelling and grammar.
- Make sure the link works and points to the canonical source (GitHub repo for code, original URL for content).
- New categories are welcome if your entry doesn't fit an existing one — keep the Table of Contents in sync.

## Updating your pull request

If a maintainer asks for changes, please make them — we want to merge good additions. Run `npx awesome-lint` locally to catch formatting issues before submitting.

Thank you for your suggestions!
